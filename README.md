**🎓 Rosseti_2_end** — дипломный проект: веб-приложение на FastAPI.
- **Что внутри:** аутентификация по JWT, работа с БД через SQLAlchemy (async), миграции Alembic, серверный рендеринг Jinja2, тесты.
- **Чему научился:** структурировать проект, работать с миграциями и разделять логику и представление.
- **Ссылка:** [Rosseti_2_end](https://github.com/Strannik-dev/Rosseti_2_end)

**🤖 SBRBOT** — Discord-бот для управления радиостанцией через RadioBOSS.
- **Что внутри:** приём заявок от слушателей (`!request`), поиск треков, панель ведущего, интеграция с RadioBOSS Web API, работа с `discord.py`, `aiohttp` и `yt-dlp`.
- **Чему научился:** писать асинхронных ботов, интегрироваться с внешними API и автоматизировать рутину для реального использования.
- **Ссылка:** [SBRBOT](https://github.com/Strannik-dev/SBRBOT)

**💻 Sleepmaster** — планировщик спящего режима для Windows и Linux.
- **Что внутри:** графический интерфейс, настройка расписания, кроссплатформенная сборка, работа с системными командами.
- **Чему научился:** делать утилиты с GUI и собирать их под разные ОС.
- **Ссылка:** [Sleepmaster](https://github.com/Strannik-dev/Sleepmaster)
